# AI Email Assistant - Chrome Extension (Manifest V3)

This directory contains the Chrome Extension Manifest V3 configuration and side panel loader.

## How to load in Chrome:
1. Open Google Chrome and navigate to `chrome://extensions`.
2. Toggle on **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select this `extension` directory.
5. Ensure your Next.js frontend is running on `http://localhost:3000` (or update `sidepanel.html` with your production URL).
6. Click the extension toolbar icon to open the Side Panel.
